# Prompt para cerrar módulo

```text
Revisa la evaluación del módulo y determina, con mi confirmación explícita, si corresponde:
- aprobación del módulo;
- evaluación pendiente;
- refuerzo;
- cierre con alcance reducido.

Resume:
- conceptos dominados;
- conceptos débiles;
- errores recurrentes;
- reglas de decisión útiles;
- distractores que debo reconocer.

Identifica archivos que deben cambiar:
- docs/PROGRESO.md;
- registros/ERRORES.md;
- registros/CONCEPTOS_DEBILES.md;
- registros/HISTORIAL_EVALUACIONES.md;
- modulos/NN-nombre-del-modulo/RESULTADO.md;
- otros archivos estrictamente necesarios.

Genera instrucciones para Codex.
No modifiques Git directamente.
No marques el módulo como completado sin mi aprobación explícita.
```
