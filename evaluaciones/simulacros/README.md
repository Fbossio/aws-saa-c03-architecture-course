# Simulacros

Esta carpeta almacenará simulacros por dominio e integrales.

Los simulacros deben:

- usar opción múltiple o respuesta múltiple;
- indicar número de respuestas correctas;
- cubrir dominios y tareas oficiales;
- separar intento, soluciones y feedback;
- no afirmar que las preguntas proceden del examen oficial.
