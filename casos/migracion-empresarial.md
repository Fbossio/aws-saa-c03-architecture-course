# Migración de aplicación empresarial

## Propósito didáctico

Practicar conectividad híbrida, migración de datos, continuidad, DR y modernización gradual.

## Contexto empresarial

Una empresa necesita migrar una aplicación heredada con dependencias internas y datos críticos.

## Usuarios

Personal interno, sistemas empresariales, equipo de soporte y equipo de migración.

## Requisitos funcionales

Conectar entornos, mover datos, mantener operación y reducir interrupciones.

## Requisitos no funcionales

Seguridad, compatibilidad, continuidad, recuperación y bajo riesgo de cambio.

## Restricciones

No se ejecutarán migraciones reales ni herramientas operativas.

## Estado inicial

Caso base sin arquitectura definitiva.

## Preguntas abiertas

- Qué dependencias no pueden cambiar.
- Qué ventana de interrupción es aceptable.
- Qué datos requieren sincronización continua.

## Decisiones futuras

Evaluar Site-to-Site VPN, Direct Connect, Storage Gateway, DataSync, DMS, Application Migration Service y estrategias de DR.
