# Casos

Los casos son escenarios acumulativos para practicar razonamiento arquitectónico. Evolucionarán módulo a módulo con decisiones registradas, no con implementación técnica.

Cada caso inicia sin solución final. Las decisiones futuras se incorporarán cuando el módulo correspondiente aporte criterios suficientes.
