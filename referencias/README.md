# Referencias

Esta carpeta no debe usarse para redistribución de material comercial protegido.

Las referencias externas deben registrarse en `docs/FUENTES.md` con propósito, prioridad, fecha de verificación y observaciones.

Los PDFs originales, diapositivas comerciales y otros materiales protegidos permanecerán fuera del repositorio o en fuentes privadas autorizadas. Cuando corresponda, usar enlaces o referencias en vez de copiar documentos.
