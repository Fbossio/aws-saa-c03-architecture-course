# Módulos

Las carpetas individuales de módulos se crearán cuando cada módulo vaya a iniciarse o cuando el diseño definitivo del curso quede aprobado.

Estructura futura:

```text
modulos/
└── NN-nombre-del-modulo/
    ├── MODULO.md
    ├── EVALUACION.md
    └── RESULTADO.md
```

- `MODULO.md` contiene el material aprobado.
- `EVALUACION.md` contiene preguntas y guía de revisión.
- `RESULTADO.md` contiene el desempeño personal.

Las respuestas correctas no deben quedar expuestas antes del intento cuando se use el archivo directamente.
